How to evaluate context in an LLM workflow

Start with one task and a clear definition of success. For ticket triage, a useful result might include a routing queue, a priority, and evidence from the ticket that supports both.

  1. Establish a baseline. Run the same tickets with the task instructions and no extra context. Record routing accuracy, schema validity, and how often a reviewer corrects the result.
  2. Change one source at a time. Add a queue policy, then try a few labeled examples in a separate run. Hold the model and test cases fixed so you can compare the effect of each addition.
  3. Test conflicting evidence. Include a ticket that resembles an old example but falls under a newer routing rule. Check whether the model follows the current policy and can point to the evidence behind its decision.

Track latency and review effort alongside accuracy. A small gain on routine tickets can be outweighed by extra review on ambiguous cases.
