ContextBench: Evaluating Context Engineering Strategies for Reliable LLM Workflow Automation

ContextBench is an open-source benchmark framework for evaluating how context strategies affect LLM workflow reliability. Its initial software-ticket-triage task keeps the task set fixed while comparing prompt-only, RAG-only, steering-document-only, memory-file-only, and combined-context conditions.

The benchmark tracks classification quality, JSON/schema validity, instruction following, evidence behavior, confidence, human-review burden, latency, and token usage when available. The goal is to make context-engineering decisions measurable and reproducible rather than treating context as an opaque prompt-design choice.

What can be reused

  • A fixed ticket-triage dataset and gold labels.
  • Six explicit context conditions.
  • Metrics for classification, schema adherence, evidence use, confidence, review burden, and operational behavior.
  • Run artifacts that make prompts, outputs, errors, and configurations inspectable.
